# vitest-runner v1.11.3 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `next` → `master`

---

## Overview

`src/index.cjs`, published as `dist/index.cjs`, is now the generic CommonJS shim shared by the CLDMV libraries. `require("@cldmv/vitest-runner")` returns exactly what it did before: the module object, the same exports `import` gives.

The Node.js requirement for `require()` is unchanged (`>=22.13.0`), and so is the `ERR_REQUIRE_ESM` message on older versions. Nothing else in the package changed.

---

## 📦 Packaging

### The CommonJS entry is the generic shim ([#169](https://github.com/CLDMV/vitest-runner/pull/169))

- The entry used to be `module.exports = require("./index.mjs")`. It now uses the shim every CLDMV library ships: the same Node version guard, then `require("./index.mjs")`, returning the single exported value when there is only one and the module object otherwise. vitest-runner exports several values, so `require()` still returns the module object.
- The CJS test now checks, in a plain Node.js process, that `require()` has the same keys as the ESM namespace and the same value for each one, for both `src/index.cjs` and the built `dist/index.cjs`.
