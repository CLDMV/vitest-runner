# vitest-runner v1.4.3 Changelog

**Release Date**: September 2026
**Release Type**: Patch
**Branch**: `release/1.4.3`

---

## Overview

Two build-output fixes: the published `dist/` is now actually minified as intended, and `dist/index.cjs` is a small synchronous shim instead of a second, independently-bundled copy of the whole module. No API changes.

---

## 🐛 Bug Fixes

### The published build wasn't minified (#45)

`tsup.config.mjs` had `minify: false` since the initial build setup, with no reason to keep it off — sourcemaps stay generated (and excluded from the published tarball) regardless, so minification doesn't affect local debugging via a repo checkout. `dist/index.mjs` drops from ~50KB to ~25KB and `bin/vitest-runner.mjs` from ~58KB to ~30KB.

### `dist/index.cjs` duplicated the entire module instead of wrapping it (#46)

tsup was compiling `src/runner.mjs` into two independent bundles, one per output format, so `dist/index.cjs` (27.5KB minified) contained a full second copy of the module's logic rather than being a thin wrapper around `dist/index.mjs`. Node's `require()` can load an ES module synchronously and read its exports directly as long as the module has no top-level await, which `src/runner.mjs` doesn't — so `dist/index.cjs` is now a static, hand-written shim (`src/cjs-shim.cjs`, copied in by a tsup `onSuccess` hook) that just requires the real ESM build, matching `@cldmv/uuid`'s `index.cjs` pattern. 912 bytes instead of 27.5KB, and it can't drift from `runner.mjs`'s actual exports since it re-exports the whole module namespace rather than a hand-maintained name list.

---

## Upgrade notes

No breaking changes — drop-in for v1.4.2. `require("@cldmv/vitest-runner")` still returns the same named exports (`run`, `resolveBin`, `discoverVitestFiles`, `makeRunTmpDir`, and the rest); only what backs the CJS build changed, not its shape.
