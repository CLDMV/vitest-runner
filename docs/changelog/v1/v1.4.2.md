# vitest-runner v1.4.2 Changelog

**Release Date**: September 2026
**Release Type**: Patch
**Branch**: `release/1.4.2`

---

## Overview

A same-day follow-up to v1.4.1: the `prepack` fix in that release stopped the publish job crashing before it ever reached the registry, and that uncovered the next failure in the chain — npm rejected the publish outright because `package.json` was missing `repository`/`bugs`/`homepage` fields entirely. No API changes.

---

## 🐛 Bug Fixes

### npm rejected the publish over a missing `repository.url` (#43)

npm's provenance verification failed with `422 Unprocessable Entity — Error verifying sigstore provenance bundle: Failed to validate repository information: package.json: "repository.url" is "", expected to match "https://github.com/CLDMV/vitest-runner" from provenance`. `package.json` never had `repository`, `bugs`, or `homepage` fields — this has been broken since the repo's creation but never surfaced because every prior publish attempt already failed earlier, in `prepack` (fixed in v1.4.1). GitHub Packages' publish was unaffected — it doesn't perform the same provenance check — so v1.4.1 exists there but was never actually published to npm; v1.4.2 is the first version of the current `dist/`-based build to reach the npm registry. All three fields now match the convention already used in `@cldmv/uuid` and `@cldmv/fix-headers`.
