# vitest-runner v1.9.0 Changelog

**Release Date**: November 2026
**Release Type**: Minor
**Branch**: `next` → `master`

---

## Overview

A test file that never finished used to hold the whole run forever: the runner waited on each file's process with no time limit, so one hung file meant no progress and no report. One browser test's unbounded wait held a full rummage run for 80 minutes. Each file now has a time limit and an idle limit. A file that hits either is killed with its whole process group, reported as failed with the reason and its last output, and the run carries on.

Both limits are on by default (30 minutes to run, 10 minutes without output). Files also run in their own process group now, and the runner kills those groups itself on Ctrl-C, SIGTERM and exit.

---

## ✨ Features

### Per-file watchdog ([#144](https://github.com/CLDMV/vitest-runner/pull/144))

- **Time limit:** `fileTimeoutMs`, `--file-timeout <s>` or `VITEST_FILE_TIMEOUT` (seconds). Default 30 minutes.
- **Idle limit**, for a file that prints nothing: `fileIdleTimeoutMs`, `--file-idle-timeout <s>` or `VITEST_FILE_IDLE_TIMEOUT` (seconds). Default 10 minutes.
- `0` turns a limit off. `perFileTimeoutOverrides: [{ pattern, timeoutMs?, idleTimeoutMs? }]` sets limits for known slow files; the first matching path substring wins and replaces the limits it sets.
- When a limit is hit, the file's process group gets SIGTERM and, 5 seconds later, SIGKILL. The file is reported as failed with the reason and its last 20 lines of output, and its result in the JSON report has a `timedOut` field with the reason.
- A process that moves itself out of the group (a new session) isn't reached by the kill. If it keeps the file's output pipes open, the runner reports the file anyway after one more grace period.
- `killChildProcessGroups()` kills every live file's process group, and `liveChildCount()` says how many are running.

Fixes [#124](https://github.com/CLDMV/vitest-runner/issues/124).

## 🔁 Behaviour changes

- Each test file runs in its own process group (POSIX), so the kill reaches vitest's workers and anything a test started, such as a browser. Those processes no longer get the terminal's Ctrl-C directly. The runner now handles SIGINT and SIGTERM itself on every run, killing the live groups, and also kills them when the process exits. Before, with `keepTmp`, the runner set no handler and Node's default exit could leave the children running.
- On Windows there are no process groups, so a timeout kills the file's own process only.

## Upgrade notes

- No API breaks. A file that runs longer than 30 minutes, or prints nothing for 10 minutes, now fails instead of running on. Vitest's default reporter can print little while one long test runs, so a file that is silent for more than 10 minutes on purpose needs `fileIdleTimeoutMs`, `--file-idle-timeout` or a `perFileTimeoutOverrides` entry.
