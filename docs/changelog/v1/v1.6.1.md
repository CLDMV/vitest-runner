# vitest-runner v1.6.1 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `next` → `master`

---

## Overview

v1.6.0 raised `engines.node` from `>=22.12.0` to `>=22.22.0`. That number is the floor of the build and test toolchain, not something the runner needs to run. This release sets `engines.node` to `>=22.0.0`, the floor of the runner's only runtime dependency (`chalk` 6), and records the toolchain floor separately in npm's `devEngines`. Node.js 22 releases before 22.22.0 can install v1.6.x without an `EBADENGINE` warning.

The runner's options, behavior and exports are unchanged. The CommonJS entry's error message and the build target are the only other changes to what ships.

---

## 🐛 Bug Fixes

### `engines.node` describes the runtime ([#115](https://github.com/CLDMV/vitest-runner/pull/115))

- `engines.node` is `>=22.0.0` instead of `>=22.22.0`, matching `chalk` 6.0.1 (`>=22`). The Vitest version you install still has its own Node.js floor.
- The CommonJS entry's `ERR_REQUIRE_ESM` message now says `require()` needs Node.js >=22.13.0 instead of >=22.22.0. Node.js 22.x before 22.12 has no `require(esm)`, and 22.12.x prints an `ExperimentalWarning` when it loads the ES module build, so `require()` is supported from 22.13.0. On 22.0 through 22.12, load the runner with `import()`.
- The tsup build targets `node22` instead of `node20`.

---

## 📦 Requirements

- **Runtime:** Node.js `>=22.0.0` (`engines.node`) for `import`, and >=22.13.0 for `require()`. Node.js 20 is still unsupported; stay on v1.5.1 there. The `vitest` peer range (`>=1.0.0`) is unchanged.
- **Development:** Node.js 22.22.0 or later, declared in the new `devEngines.runtime` field (`onFail: "error"`), so npm stops with an error when it is run in a checkout on an older Node.js.

## 🔧 CI & tooling

- The `min_node_version` input descriptions and a comment in `ci.yml` and `publish.yml` now say the 22.22.0 matrix floor is the dev toolchain floor and should match `devEngines`, not `engines` ([#115](https://github.com/CLDMV/vitest-runner/pull/115)). The matrix itself still starts at 22.22.0.
