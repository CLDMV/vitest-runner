# vitest-runner v1.5.6 Changelog

**Release Date**: October 2026
**Release Type**: Patch
**Branch**: `next` → `master`

---

## Overview

A dev-tooling dependency release that brings every open dependency update into one change ([#104](https://github.com/CLDMV/vitest-runner/pull/104)) and clears the two open Dependabot alerts, both in development dependencies. The build tool moves to `tsup` 9, and the test toolchain moves to Vitest 5.0.5.

Nothing a consumer installs changes. The runtime dependency `chalk` and the `vitest` peer range are untouched, and the built `dist/` and `bin/` files are byte-identical to [v1.5.5](./v1.5.5.md): the `tsup` 9 build produces exactly the same output as `tsup` 8, on Node.js 26 and on Node.js 22.12, the oldest version CI tests.

---

## 🔒 Security

Both alerts were in development dependencies only; neither affected the published package.

- **`esbuild` 0.27.7 → 0.28.2** ([GHSA-g7r4-m6w7-qqqr](https://github.com/advisories/GHSA-g7r4-m6w7-qqqr), low). The advisory covers esbuild's development server on Windows, which this repository never runs; esbuild is only used through `tsup` to bundle. Fixed by the `tsup` 9 update below.
- **`katex` 0.16.47 → 0.19.1** ([GHSA-238p-pmpm-9mq7](https://github.com/advisories/GHSA-238p-pmpm-9mq7), low). `katex` comes in through `@eslint/markdown` → `micromark-extension-math`, whose latest release still requires `katex ^0.16`, so no regular update could reach the fix. An npm override, `"katex": ">=0.18.2"`, now resolves it to the newest release. `katex` never runs here, because the Markdown lint config leaves math parsing off, but math rendered through `micromark-extension-math` still works with the newer version. The override can be removed once `micromark-extension-math` allows `katex` 0.18.2 or later itself.

## 🔧 Dependencies

All dev-only ([#104](https://github.com/CLDMV/vitest-runner/pull/104), replacing [#88](https://github.com/CLDMV/vitest-runner/pull/88), [#90](https://github.com/CLDMV/vitest-runner/pull/90), [#92](https://github.com/CLDMV/vitest-runner/pull/92), [#93](https://github.com/CLDMV/vitest-runner/pull/93), [#95](https://github.com/CLDMV/vitest-runner/pull/95) and [#97](https://github.com/CLDMV/vitest-runner/pull/97)).

- **`tsup` `^8.5.1` → `^9.0.0`**, a major version of the build tool. It declares Node.js `^22.18.0 || ^24.11.0 || >=26.0.0`, above the package's own `>=22.12.0`; on Node.js 22.12 it builds the same files, with only an npm engine warning.
- **`vitest` and `@vitest/coverage-v8` → `^5.0.5`**. Vitest 5.0.5 turns `fsModuleCache` on by default, so the runner's own fs-cache tests now set it explicitly instead of relying on the default.
- **`vite` 8.3.4 → 8.3.5** and **`source-map-js` 1.2.1 → 1.2.2** (lockfile only).
- **`@cldmv/fix-headers` → `^2.2.2`**; re-running `fix:headers` changed no file.
- **`@eslint/json` → `^2.1.1`** and **`@types/node` → `^26.6.5`**.
