# vitest-runner v1.11.2 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `next` → `master`

---

## Overview

A CI-only release. `ci.yml` takes the concurrency block from the CLDMV/.github v4.46.0 template, so a newer push to `next` or `hotfixes` now cancels the run it supersedes instead of letting every run finish.

No runtime code changed. The published package is the same as v1.11.1 apart from the version number.

---

## 🔧 CI & tooling

### Cancel superseded CI runs on next and hotfixes ([#166](https://github.com/CLDMV/vitest-runner/pull/166))

- Runs on `next`, `hotfixes` and the release PR used to get a unique concurrency group each, so none of them was ever cancelled. A burst of pushes there could hold many hosted runners at once, and across the org that once left every other repository's jobs queued.
- Only pushes to the release base branch (`CLDMV_RELEASE_BASE`, else the default branch) still get a unique group, because each of those is a release and has to finish. Everything else shares a per-ref group with `cancel-in-progress: true`, so the newest commit's run is the one that reports.

Fixes [#165](https://github.com/CLDMV/vitest-runner/issues/165).
