# vitest-runner v1.8.2 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `next` → `master`

---

## Overview

A dev-tooling dependency release. The repository's own test toolchain moves to Vitest 5.1.1, along with ESLint 10.15 and Prettier 3.10 ([#128](https://github.com/CLDMV/vitest-runner/pull/128)). It also brings the repository's CI coverage back to 100%.

No runtime code changed. `package.json` is unchanged, including the `vitest` peer range, so only the lockfile moves.

---

## 🔧 Dependencies

All dev-only, lockfile only ([#128](https://github.com/CLDMV/vitest-runner/pull/128)).

- **`vitest` and `@vitest/coverage-v8` 5.0.5 → 5.1.1.**
- **`eslint` 10.14.0 → 10.15.0.**
- **`prettier` 3.9.10 → 3.10.1.** The repository's files format the same.

---

## 🧪 Tests

- Coverage is back to 100% on CI. On CI's checkout path the socket for the "stale root whose removal fails" sweep test came to 108 characters, one over the Unix socket limit, so the sweep read the root as unknown instead of dead and never reached the code the test is for. CI measured 15 of 16 functions in `scratch.mjs` and the badge showed 99.8%. The test's folder name is shorter now, and the helper that builds a dead root fails the test if the root doesn't read as dead ([#143](https://github.com/CLDMV/vitest-runner/pull/143)).
- `ci:coverage` runs the coverage run after `test:dist` and `test:cjs`. Their fixture runs had been writing empty `coverage-final.json` and `clover.xml` files over the real reports, so the coverage artifact CI uploads had no per-file detail. Fixes [#142](https://github.com/CLDMV/vitest-runner/issues/142) ([#143](https://github.com/CLDMV/vitest-runner/pull/143)).
- Vitest 5.1 clears its fs module cache by renaming the directory aside and then removing the renamed copy, where 5.0 removed it in place. The fs-cache test's probe only counted the in-place removal, so it saw no clear. It now also counts a successful rename away from the cache directory, and the test passes on both versions ([#128](https://github.com/CLDMV/vitest-runner/pull/128)).
